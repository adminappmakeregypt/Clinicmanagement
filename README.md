# حجز العيادات - Clinic Booking App

تطبيق ويب بسيط لحجز مواعيد العيادات باللغة العربية. يحتوي على نموذج متعدد الخطوات، ملخص حجز مباشر، وسجل حجوزات مع إمكانية التعديل والحذف.

## الملفات
- `index.html` - الواجهة
- `styles.css` - التنسيق
- `script.js` - المنطق (يحفظ البيانات في localStorage)

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو ارفع الملفات إلى GitHub Pages.

## إضافة حساب عيادة
- أنشئ البريد وكلمة المرور أولاً في Firebase Authentication ضمن مشروع `bookmydoctor-6c93c`.
- أضف البريد بحروف صغيرة إلى `EMAIL_MAP` في `auth.js` وحدد `clinicId` و`role`.
- استخدم `role: "admin"` للمدير أو `role: "user"` للمستخدم العادي.
- ارفع الملفات إلى GitHub Pages. تم وضع رقم إصدار على `auth.js` لمنع تحميل قائمة حسابات قديمة من ذاكرة المتصفح.

## المزايا
- نموذج بخمس خطوات (اسم، مرض، تاريخ، وقت، تأكيد)
- ملخص حجز مباشر
- سجل حجوزات مع بحث
- تعديل وحذف الحجوزات
- يدعم RTL بالكامل
